## About

This repository tracks my progress through the **Optimal Odyssey** SoC project, which explores the **Travelling Salesman Problem (TSP)** — one of the most famous problems in combinatorial optimization.

Over 8 weeks, the project builds from foundational graph algorithms all the way up to metaheuristic optimization techniques, culminating in a benchmarked implementation and report.
